# Configuration

## Color Palettes

Materialistic Jekyll Theme comes with 50 pre-generated color palettes. You can set the global palette in `_config.yml`:

```yaml
theme_settings:
  palette: "palette-1"
```

Or override it per page:

```yaml
---
palette: "palette-10"
---
```

## Navigation

The sidebar navigation is automatically generated based on the pages in your project.
