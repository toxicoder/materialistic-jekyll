# Material 3 Components

The Materialistic Jekyll Theme provides a comprehensive implementation of Material Design 3 components. These components are designed to be used directly in your Markdown files or HTML layouts.

## Usage

Most components are implemented as CSS classes. You can use them by:

1. **HTML Syntax**: Directly writing HTML tags with the appropriate classes.
   ```html
   <button class="btn btn-primary">Click Me</button>
   ```

2. **Kramdown Attribute Lists**: Applying classes to Markdown elements (where supported).
   ```markdown
   **Primary Button**
   {: .btn .btn-primary }
   ```

## Categories

The components are organized into the following categories:

- [**Buttons**](/docs/components/buttons/): Common actions and triggers (Buttons, FABs, Icon Buttons).
- [**Inputs & Controls**](/docs/components/inputs/): Form inputs and selection controls (Text Fields, Checkboxes, Switches).
- [**Content & Display**](/docs/components/content/): Layout and data display (Cards, Lists, Chips, Tables).
- [**Layout & Navigation**](/docs/components/layout/): Structural and navigational elements (Tabs, Dialogs, Menus).
